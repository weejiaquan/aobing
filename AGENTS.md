# Project design guidance

Before changing the interface, branding, artwork, copy, or animation, read
[docs/design-spec.md](docs/design-spec.md). It records the owner's accepted design
direction, removed copy, motion requirements, implementation map, and review checks.

Preserve those decisions unless the user requests a change. New user instructions
take precedence; update the spec when a new design decision is accepted so future
sessions inherit the current direction. Keep game-shell changes separate from
gameplay logic where practical.
